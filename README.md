# Tattoo Forge MVP

Это минимальный MVP с интерфейсом и серверным endpoint для генерации изображений через OpenAI Images API.

## Файлы
- `index.html` — интерфейс для телефона.
- `api/generate.js` — серверный endpoint, хранит API-ключ только на сервере.
- `package.json` — конфигурация проекта.

## Деплой на Vercel
1. Импортируй репозиторий в Vercel.
2. В Vercel открой Project Settings → Environment Variables.
3. Добавь `OPENAI_API_KEY` со своим секретным API-ключом.
4. Сделай Redeploy после добавления переменной.

## Важно
- Не вставляй API-ключ в `index.html` и не публикуй его в GitHub.
- Генерация изображений через API может быть платной; проверь доступность модели и лимиты своего аккаунта.
- MVP пока хранит коллекцию только в памяти страницы. Постоянное хранение, вход пользователей, лимиты и платёжную систему добавим отдельно.
